# Historical equipment references

## In-game recognition icons

The deployment dock and map use the ten simplified SVG silhouettes in `icons/`. They were drawn for this project from the reference images below so that every equipment type stays readable at dock and map scale. The icons are original project artwork and do not embed third-party artwork.

- `icons/panzer-iv.svg`
- `icons/stug-iii.svg`
- `icons/tiger-i.svg`
- `icons/t34-76.svg`
- `icons/kv-1.svg`
- `icons/su-76.svg`
- `icons/katyusha.svg`
- `icons/nebelwerfer.svg`
- `icons/ju-87.svg`
- `icons/il-2.svg`

## Reference images

These files are kept for provenance and comparison. The game no longer loads the older raster/vector files.

- `panzer-iv.png` - [Panzer IV G.svg](https://commons.wikimedia.org/wiki/File:Panzer_IV_G.svg), public-domain release by Marseille77.
- `tiger-i.svg` - [Panzer VI tiger.svg](https://commons.wikimedia.org/wiki/File:Panzer_VI_tiger.svg), public-domain release by the author.
- `panzer-iii-iv.svg` - [Panzer IIIIV.svg](https://commons.wikimedia.org/wiki/File:Panzer_IIIIV.svg), CC BY-SA; retained as a reference only.
- `t34-top.png` - [T-34 top view vector.svg](https://commons.wikimedia.org/wiki/File:T-34_top_view_vector.svg), public-domain release by the author.
- `t34-85.png` - visual reference only; source not recorded.
- `kv1.png` - visual reference only; source not recorded.
- `ju-87-stuka.png` - [Junkers Ju 87B-2 Stuka.svg](https://commons.wikimedia.org/wiki/File:Junkers_Ju_87B-2_Stuka.svg), downloaded as a Commons thumbnail.
- `il-2.png` - [Ilyushin Il-2 and Il-2-37 top-view silhouettes.png](https://commons.wikimedia.org/wiki/File:Ilyushin_Il-2_and_Il-2-37_top-view_silhouettes.png).
